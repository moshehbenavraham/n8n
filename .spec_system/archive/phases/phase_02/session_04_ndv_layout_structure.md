## Objective

Apply Obsidian Forge styling to the Node Details View (NDV) three-panel layout structure, including the header, panel dividers, tab navigation, and overall container chrome.

---

## Scope

### In Scope (MVP)
- NDV container background and borders
- NDV header styling (node name, icon, close button)
- Three-panel layout dividers and resize handles
- Tab navigation styling (Settings, Input, Output, etc.)
- Panel header/title styling within each pane
- Scroll containers and overflow handling
- Panel collapse/expand animations
- NDV footer bar styling (if present)
- Responsive breakpoint behavior
- Panel shadow and depth hierarchy

### Out of Scope
- Form input components within panels (Session 05)
- CodeMirror code editor (Session 05)
- Individual field styling (Session 05)
